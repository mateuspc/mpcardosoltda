# Site institucional

Site da M P Cardoso Solutions construído com React, TypeScript e Vite. As páginas de produtos e documentos públicos ficam em `public/` para preservar URLs diretas e estáveis.

## Comandos

```bash
npm ci
npm run dev
npm run lint
npm run build
```

O tema corporativo usa a identidade azul-marinho, azul elétrico, ciano e lima. As páginas próprias de PitchPro, Car Audio Box e Atlas do Vinho mantêm suas identidades de produto.
